Import Word documents and fixed PDFs

Word headings, paragraphs, lists, text tables and embedded PNG or JPEG images become editable blocks. Quote tables need a price column and can name Quantity and SKU. Rows match the catalog by SKU, then by name. Unmatched rows retain their written names and prices. Missing image sources are listed; absent quote images cannot be recovered.

PDF pages remain in their original file, byte for byte. Append blocks and pricing after those pages. A field or signature can name an original page and a position in PDF points. Download the original separately from the composed unsigned proposal.
