# Rethink Sans

Rethink Sans is self-hosted under the SIL Open Font License 1.1 in
`rethink-sans/OFL.txt`. The Latin variable WOFF2 (400–800) comes from
Fontsource’s Rethink Sans distribution, version 5.3.0. Upstream:
https://github.com/hans-thiessen/Rethink-Sans.

`fonts.css` declares the face once. The shared Platter theme maps it to body
and heading tokens. All font requests stay on this installation.
